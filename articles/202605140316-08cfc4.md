## はじめに：なぜ今、Matterportを改めて見直すのか

BIM推進担当として日々設計部門や現場と向き合っていると、「3Dモデルはあるのに、現場の実態とのギャップが埋まらない」という壁にぶつかります。設計BIMと施工BIMの間、あるいは竣工後のFMフェーズへの引き渡し時に、**現実空間のリアリティ**をどうデータ化するか。その有力な解の一つが、3Dキャプチャープラットフォームの**Matterport**です。

今週は同社から法人向けの新しいメッセージングが発信され、また周辺の開発トレンド（AIエージェントやマルチモーダルAPI）にも見逃せない動きがありました。本稿では、Matterportを軸に今週のトピックを整理し、ゼネコンの一貫BIM推進という観点から考察します。

## 今週のMatterport関連トピック

### 1. 法人向け3Dインサイトによるポートフォリオ管理の打ち出し

Matterport公式が打ち出したのは、[没入感のある3Dでキャプチャーして、共有・コラボレーションしましょう。](https://matterport.com/ja?utm_source=chatgpt.com)というメッセージ。注目すべきは、単なる「物件の3Dビューワー」から、**グローバルポートフォリオ管理ツール**への明確な舵切りです。

- 経営判断の一元化（複数拠点の3Dデータを統合）
- 職場計画（ワークプレイス改修）の迅速化
- リスク軽減（現地に行かずに状況把握）

建設業の文脈に置き換えれば、これは**多現場を抱えるゼネコンの本社管理機能**や、**発注者の竣工後FM**に直結する話です。

### 2. AI・マルチモーダル基盤の進化が3Dデータの価値を底上げする

直接Matterportを扱った記事ではありませんが、[Lambda Just Got a File System. I Put AI Agents on It.](https://dev.to/aws/lambda-just-got-a-file-system-i-put-ai-agents-on-it-1ej8)では、サーバーレス環境でAIエージェントが大容量ファイルを扱える時代になったことが示されています。3Dスキャンデータのような**重いアセットの自動処理**が現実的になりつつあるということです。

さらに[Gemini API File Search: Enhanced Multimodal Capabilities with Embedding 2](https://dev.to/gde/gemini-api-file-search-enhanced-multimodal-capabilities-with-embedding-2-including-open-source-g72)では、画像を含むマルチモーダル検索の高度化が紹介されています。Matterportが蓄積する点群・パノラマ画像群に対し、**「ひび割れがある箇所を検索」「鉄骨の建て方が完了したスパンを抽出」**といった自然言語クエリが現実的になる未来は、もうすぐそこです。

## ゼネコンBIM担当としての独自考察


:::message
### 既存業務への応用可能性

当社のような中堅・準大手ゼネコンでMatterportが効きそうなフェーズは、私見では以下の3つです。

- **施工中の出来形記録**：週次でスキャンし、BIMモデルと重ね合わせて干渉・施工誤差を確認。協力会社との「言った/言わない」問題の証跡にもなる。
- **改修・リニューアル案件の初期調査**：現調工数を大幅削減。設計部門への情報共有もURL一本で済む。
- **発注者への引き渡し・FM連携**：竣工BIMに3Dウォークスルーを添付することで、発注者側の「BIMリテラシー差」を埋められる。

### 社内標準化への活かし方

一貫BIMの標準化において課題なのは、**「設計BIMが施工段階で更新されない」**問題です。Matterportを**定点観測の標準ツール**として位置づけ、撮影頻度・命名規則・保管場所をルール化すれば、BIMモデルと現実の差分管理が回り始めます。Revitやarchicadのモデルとリンクさせるワークフローを社内標準書に組み込むのが現実的な第一歩でしょう。

### 現実的な導入ハードル

- **コスト構造**：撮影機材＋クラウド月額のランニング費を、案件採算にどう乗せるか。全社プールか案件配賦かの議論が必要。
- **協力会社のリテラシー**：閲覧は容易だが、撮影オペレーションを誰が担うのか。専門業者委託か内製化かの判断。
- **データガバナンス**：発注者の機密情報を含む3Dデータをクラウドに置く際の、情報セキュリティ部門との調整。
- **BIMとの連携深度**：単なる「ビューワー併用」で終わらせず、点群・属性情報のやり取りまで踏み込めるか。
:::


## 総括

Matterportは、もはや「綺麗な3Dビューワー」ではなく、**現実空間をBIMエコシステムに取り込む基盤**へと進化しつつあります。AIマルチモーダルの進化と組み合わさることで、ゼネコンが抱える「設計と現場の乖離」「発注者との情報非対称」を埋める現実的なツールになる可能性が高い。若手BIM担当としては、**小規模案件でのPoCを起点に、標準化フローへ落とし込む**動きを今期中に仕掛けたいところです。導入のハードルは確かにありますが、「既存BIMと組み合わせて何ができるか」という視点で見れば、投資対効果は十分説明できると感じています。
